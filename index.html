Unidad 2

1. Estructuras Condicionales

Permiten que un algoritmo tome diferentes caminos según una condición.

A. Condicional Simple (Si-Entonces)

Ejecuta una acción solo cuando la condición es verdadera.

B. Condicional Compuesta (Si-Entonces-Sino)

Permite elegir entre dos caminos posibles.

C. Condicional Múltiple (Según Sea / Switch)

Evalúa una variable entre varias alternativas.

2. Estructuras Repetitivas

A. Mientras (While)

Evalúa la condición antes de ejecutar el ciclo.

B. Repetir-Hasta

El bloque se ejecuta al menos una vez.

C. Para (For)

Se utiliza cuando se conoce el número de repeticiones.

3. Ejercicio Integrador

Una tienda procesa compras de N clientes.

  • Compra mayor a $100 → descuento del 15%.
  • Compra menor o igual a $100 → sin descuento.
  • Mostrar pago final y total recaudado.

4. Reflexión Crítica

Las estructuras condicionales y repetitivas permiten que la computadora tome decisiones y procese información automáticamente. Una buena planificación de la lógica antes de programar facilita la solución de problemas.
